# 制約と未検証事項

2026-11-27（JST）に Docker 28.4.0、k3d 5.9.0、k3s v1.31.5+k3s1、kubectl v1.34.1 の専用クラスタで探索的試行を実行した。通常のサンドボックスから Docker ソケットへのアクセスは拒否されたが、許可された実行境界からはアクセスできた。各試行の実行環境と成否は `experiment_metadata.json` に保存する。別環境で実行できない場合、シミュレーション結果を実環境結果としない。

小規模な模擬サービス、HTTP プローブ、namespace 内 RBAC は実運用の認証、障害復旧、通信多様性を代表しない。Pod 内 API トークンは実験専用である。NetworkPolicy の動作は CNI に依存する。採取時刻と API resourceVersion は完全な線形化を保証しない。単一クラスタ・少数因果構造から統計的な一般化はできない。

S3 の権限リース解除・残存時間、S5 の部分欠損や RBAC 変化、異種操作の相互作用、長時間の SLO 違反、復旧目的の汎用指標は未実装である。現在の Ground Truth は正常 HTTP 成功率とダミー Secret 実アクセスの差を中心とし、DIR-I や長期 DIR-P の全種類を網羅しない。短いプローブ窓では稀な失敗を見落とす。全拒否の対照では Recovery が失敗したため、安全率だけを性能指標にしない。

各比較は探索的で、コードの修正を挟んだ試行も含む。試行 ID と保存済みソース・ハッシュを使い、正式な性能推定ではコード版を固定した新規バッチを実行する。試行中の修正で同じハッシュが異なる実装を指した事例は `docs/failure_cases.md` に記録した。LLM の独立評価、対照試行のランダム化、信頼区間の推定は行っていない。

既存のシミュレータ、過去の実験、`research_report.md`、Codex 予備実験はこのリポジトリには存在しない。したがって legacy 移動の対象はない。LLM 評価は実際のモデルを用いた試行があるまで未実施とする。
